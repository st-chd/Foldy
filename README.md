# Foldy

Foldy는 SillyTavern의 프롬프트, 로어북(월드 인포), 정규식 목록에 폴더 기능을 추가하는 확장 프로그램입니다.
항목이 많아졌을 때 관련 항목을 묶어 접어 두고, 폴더 단위로 순서와 설정을 관리할 수 있습니다.

## 주요 기능

- 프롬프트, 로어북, 정규식 목록에 폴더 추가
- 폴더와 항목의 순서 변경
- 드래그 앤 드롭으로 폴더·항목 배치 변경
- 폴더 안의 항목을 다른 폴더로 개별 또는 일괄 이동
- 미분류 항목을 한 번에 폴더로 이동
- 폴더별 접기·펼치기 및 전체 접기·펼치기
- 폴더 이름, 배경색, 테두리색, 이름 색상 설정
- 한 폴더의 색상 설정을 같은 목록의 다른 폴더에 일괄 적용
- 폴더 구조 또는 원본 내용을 포함한 번들 내보내기·불러오기
- 로어북 폴더 안 항목의 옵션 일괄 변경
- 정규식 폴더 안 스크립트의 활성화 상태 일괄 변경
- 사용 중인 데이터, 미사용 데이터, 전체 폴더 데이터 선택 초기화
- `/foldy-color` 슬래시 명령어로 폴더 색상 변경

## 지원 영역

### 프롬프트

현재 선택한 프롬프트 프리셋의 프롬프트 목록을 폴더로 정리합니다.
폴더 구조와 접힘 상태는 프리셋별로 따로 저장됩니다.

프롬프트를 새 폴더에 넣어 만들거나, 미분류 프롬프트를 일괄 이동할 수 있습니다.
원본 프롬프트의 내용과 활성화 상태는 유지됩니다.

### 로어북

로어북 편집기의 정렬 방식을 `폴더 순서`로 선택하면 Foldy 폴더 UI가 표시됩니다.
현재 선택한 로어북의 항목을 폴더로 묶고, 폴더 단위로 순서를 관리할 수 있습니다.

폴더 안의 항목에 대해 전략, 삽입 위치, 깊이, 재귀 등 로어북 옵션을 일괄 적용할 수 있습니다.
폴더 단위 활성화·비활성화도 지원합니다.

### 정규식

글로벌 정규식, 정규식 프리셋, 현재 캐릭터의 범위 정규식 목록을 각각 폴더로 정리합니다.
정규식 목록마다 폴더 구조와 접힘 상태가 독립적으로 저장됩니다.

폴더 안 스크립트의 활성화 상태를 한 번에 켜거나 끌 수 있으며, 현재 목록의 미분류 스크립트도 일괄 이동할 수 있습니다.

## 사용 방법

각 지원 목록에 Foldy 툴바가 추가됩니다.

- `폴더 추가`: 폴더를 만들고 새 항목 또는 기존 항목을 선택해 넣습니다.
- `폴더로 이동`: 항목 하나를 선택한 폴더로 이동합니다.
- `미분류 일괄 이동`: 미분류 항목 여러 개를 한 번에 폴더로 이동합니다.
- `모두 접기` / `모두 펼치기`: 현재 목록의 모든 폴더 상태를 변경합니다.
- 폴더 메뉴: 이름, 위치, 색상, 항목 설정을 변경하거나 폴더를 삭제합니다.

폴더 위치를 지정하는 입력란에서는 `폴더만`, `폴더제외`, `모두보기` 필터를 사용할 수 있습니다.
폴더는 한 단계만 지원하며, 하위 폴더를 만들 수는 없습니다.

## 내보내기와 불러오기

각 지원 영역의 툴바에서 번들을 내보내거나 불러올 수 있습니다.

| 내보내기 방식 | 포함 내용 |
| --- | --- |
| 폴더 구조만 | 현재 원본 항목은 건드리지 않고 폴더 배치와 설정만 저장 |
| 내용 포함 번들 | 원본 항목 내용과 폴더 구조를 함께 저장 |
| 선택 폴더만 | 정규식은 내보낼 폴더를 선택해 저장 가능 |

내용 포함 번들은 다른 환경으로 옮기거나 대규모 정리를 하기 전에 백업으로 사용할 수 있습니다.
불러오기 전에 기존 항목과의 충돌 여부를 확인하며, 필요한 경우 이름과 ID를 조정해 현재 목록에 병합합니다.

불러오기는 원본 내용과 폴더 구조를 변경할 수 있으므로 중요한 데이터는 먼저 백업해 두는 것을 권장합니다.

## 설정 패널

SillyTavern의 확장 프로그램 설정에서 Foldy 항목을 열면 다음 기능을 사용할 수 있습니다.

- 프롬프트 폴더 기능 켜기·끄기
- 로어북 폴더 기능 켜기·끄기
- 정규식 폴더 기능 켜기·끄기
- 프롬프트, 로어북, 정규식 폴더 데이터만 선택해 초기화
- 모든 Foldy 폴더 데이터 초기화

초기화는 기본적으로 원본 항목을 삭제하지 않고 Foldy의 폴더 구조와 접힘 상태만 삭제합니다.
폴더를 삭제할 때는 `폴더만 삭제`와 `폴더와 내용까지 모두 삭제` 중에서 선택할 수 있습니다.
내용까지 삭제한 경우 원본 항목도 삭제되며 되돌릴 수 없습니다.

## 슬래시 명령어

채팅 입력창이나 Quick Reply에서 `/foldy-color`로 현재 대상 목록의 폴더 색상을 변경할 수 있습니다.
설치 또는 업데이트 후 명령어가 보이지 않으면 SillyTavern 페이지를 새로고침하세요.

```text
/foldy-color target=prompts folder="내 폴더" reset=true
/foldy-color target=prompts folder="내 폴더" all=true
/foldy-color target=lorebooks all=true reset=true
/foldy-color target=regex-global all=true background=#202020 border=default text=#ffffff
```

| 인수 | 설명 |
| --- | --- |
| `target` | 필수. `prompts`, `lorebooks`, `regex-global`, `regex-preset`, `regex-scoped` 중 하나 |
| `folder` | 폴더 이름 또는 ID. 공백이 있는 이름은 큰따옴표로 감쌉니다. |
| `background` | 배경색. HEX, `transparent`, CSS 색상 또는 `default` |
| `border` | 테두리색. HEX, `transparent`, CSS 색상 또는 `default` |
| `text` | 폴더 이름 색상. HEX, `transparent`, CSS 색상 또는 `default` |
| `reset=true` | 세 가지 색상을 테마 기본값으로 복원합니다. 개별 색상 인수와 함께 사용할 수 없습니다. |
| `all=true` | 현재 목록의 모든 폴더에 적용합니다. 생략하면 지정한 폴더만 변경합니다. |

`folder`와 `all=true`를 함께 사용하면 해당 폴더의 세 가지 색상 설정을 같은 목록의 모든 폴더에 복사합니다.
`folder` 없이 `all=true`를 사용하면 지정한 색상만 바꾸고 나머지 색상은 각 폴더의 기존 값을 유지합니다.

명령어는 현재 선택된 프롬프트 프리셋, 로어북, 정규식 목록에만 적용됩니다.
다른 프리셋, 로어북, 캐릭터의 폴더나 원본 항목 내용은 변경하지 않습니다.

## 참고 사항

- Foldy는 현재 SillyTavern UI에 연결해 동작하므로 UI가 크게 변경되면 일부 기능이 비활성화될 수 있습니다.
- 드래그 앤 드롭이 어려운 환경에서는 `폴더로 이동` 또는 `미분류 일괄 이동`을 사용하세요.
- 미사용 데이터는 현재 존재하지 않는 프리셋, 로어북, 캐릭터 또는 정규식 목록에 남아 있는 Foldy 기록입니다.
- 로어북 폴더 UI를 사용하려면 로어북 정렬 방식을 `폴더 순서`로 설정해야 합니다.
