# Foldy

SillyTavern의 프롬프트, 로어북(월드 인포), 정규식 목록에 폴더를 추가하는 확장입니다.
항목이 많을 때 묶어서 접어 두고 폴더 단위로 순서와 설정을 관리합니다.

## 주요 기능

- 프롬프트, 로어북, 정규식 목록에 폴더 추가
- 드래그 앤 드롭으로 폴더·항목 순서 변경
- 항목을 다른 폴더로 개별·일괄 이동
- 미분류 항목을 한 번에 폴더로 이동
- 폴더별·전체 접기와 펼치기
- 프롬프트 폴더 안 구분선
- 폴더 이름, 배경색, 테두리색, 이름 색 설정
- 한 폴더의 색을 같은 목록의 모든 폴더에 적용
- 폴더 구조만, 또는 원본 내용까지 번들로 내보내기·불러오기
- 로어북 폴더 안 항목의 옵션 일괄 변경
- 정규식 폴더 안 스크립트 일괄 켜기·끄기
- 폴더 데이터 초기화 (사용 중·미사용·전체)
- `/foldy-color` 명령어로 폴더 색 변경

## 지원 영역

### 프롬프트

선택한 프롬프트 프리셋의 목록을 폴더로 정리합니다.
폴더 구조와 접힘 상태는 프리셋마다 따로 저장됩니다.
프롬프트의 내용과 켜짐 상태는 바뀌지 않습니다.

폴더 메뉴의 구분선 버튼으로 폴더 안에 구분선을 넣을 수 있습니다.
드래그로 옮기고 마우스를 올리면 나오는 `×`로 지웁니다.
구분선은 화면에만 보이고 실제 프롬프트에는 들어가지 않습니다.

### 로어북

로어북 편집기의 정렬 방식을 `폴더 순서`로 바꾸면 폴더가 표시됩니다.
선택한 로어북의 항목을 폴더로 묶어 순서를 관리합니다.

폴더 안 항목에 전략, 삽입 위치, 깊이, 재귀 같은 옵션을 한 번에 적용할 수 있고 폴더 단위로 켜고 끌 수 있습니다.

### 정규식

글로벌, 프리셋, 캐릭터(범위) 정규식 목록을 각각 폴더로 정리합니다.
폴더 구조와 접힘 상태는 목록마다 따로 저장됩니다.

폴더 안 스크립트를 한 번에 켜거나 끌 수 있습니다.

## 사용 방법

각 목록 위에 Foldy 툴바가 생깁니다.

- `폴더 추가`: 폴더를 만들고 넣을 항목을 고릅니다.
- `폴더로 이동`: 항목 하나를 폴더로 옮깁니다.
- `미분류 일괄 이동`: 미분류 항목 여러 개를 폴더로 옮깁니다.
- `모두 접기` / `모두 펼치기`: 목록의 모든 폴더를 접거나 펼칩니다.
- 폴더 메뉴: 이름, 위치, 색, 항목을 바꾸거나 폴더를 지웁니다.

폴더 위치를 고르는 칸에서는 `폴더만`, `폴더제외`, `모두보기` 필터를 쓸 수 있습니다.
하위 폴더는 만들 수 없습니다.

## 내보내기와 불러오기

각 목록의 툴바에서 번들을 내보내거나 불러옵니다.

| 내보내기 방식 | 포함 내용 |
| --- | --- |
| 폴더 구조만 | 폴더 배치와 설정만 저장 (원본 항목은 그대로) |
| 내용 포함 번들 | 원본 항목 내용과 폴더 구조를 함께 저장 |
| 선택 폴더만 | 정규식에서 원하는 폴더만 골라 저장 |
| 일괄 폴더 구조 | 확장 설정에서 모든 대상의 폴더 구조를 한 파일로 저장 |

정규식에서 폴더를 골라 내보내면 파일명에 폴더 이름이 붙습니다. 예: `global.대사.json`, `global.대사-folders.json`. 여러 폴더를 고르면 이름을 `+`로 잇습니다.

확장 설정의 `일괄 내보내기`는 지금 존재하고 기능이 켜진 프리셋·로어북·캐릭터의 폴더 구조만 담습니다.
`일괄 불러오기`는 같은 대상의 폴더 이름·색·배치를 되살립니다. 원본 내용과 켜짐 상태는 그대로 두고 없는 대상이나 기능이 꺼진 대상은 건너뜁니다. 파일에 없는 대상은 바뀌지 않습니다. ID와 대상 이름으로 맞추기 때문에, 원본 내용까지 옮기려면 내용 포함 번들을 쓰세요.

## 설정 패널

확장 설정의 Foldy 항목에서 다음을 할 수 있습니다.

- 프롬프트·로어북·정규식 폴더 기능 켜기·끄기
- 모든 대상의 폴더 구조 일괄 내보내기·불러오기
- 프롬프트, 로어북, 정규식 폴더 데이터 따로 초기화
- 모든 폴더 데이터 초기화

초기화는 원본 항목을 지우지 않고 폴더 구조와 접힘 상태만 지웁니다.
폴더를 지울 때는 `폴더만 삭제`와 `폴더와 내용까지 모두 삭제` 중에서 고릅니다.
내용까지 지우면 원본 항목도 사라지며 되돌릴 수 없습니다.


## 슬래시 명령어

채팅 입력창이나 Quick Reply에서 `/foldy-color`로 현재 목록의 폴더 색을 바꿉니다.
설치나 업데이트 후 명령어가 안 보이면 페이지를 새로고침하세요.

```text
/foldy-color target=prompts folder="내 폴더" reset=true
/foldy-color target=prompts folder="내 폴더" all=true
/foldy-color target=lorebooks all=true reset=true
/foldy-color target=regex-global all=true background=#202020 border=default text=#ffffff
```

| 인수 | 설명 |
| --- | --- |
| `target` | **필수.** `prompts`, `lorebooks`, `regex-global`, `regex-preset`, `regex-scoped` 중 하나 |
| `folder` | 폴더 이름 또는 ID. 공백이 있으면 큰따옴표로 감쌉니다. |
| `background` | 배경색. HEX, `transparent`, CSS 색상 또는 `default` |
| `border` | 테두리색. HEX, `transparent`, CSS 색상 또는 `default` |
| `text` | 폴더 이름 색. HEX, `transparent`, CSS 색상 또는 `default` |
| `reset=true` | 세 색을 테마 기본값으로 되돌립니다. 다른 색 인수와 같이 쓸 수 없습니다. |
| `all=true` | 목록의 모든 폴더에 적용합니다. 없으면 지정한 폴더만 바꿉니다. |

`folder`와 `all=true`를 같이 쓰면 그 폴더의 세 색을 같은 목록의 모든 폴더에 복사합니다.
`folder` 없이 `all=true`만 쓰면 지정한 색만 바꾸고 나머지는 그대로 둡니다.

명령어는 지금 선택된 프롬프트 프리셋, 로어북, 정규식 목록에만 적용됩니다.

## 참고 사항

- SillyTavern 화면 구조가 크게 바뀌면 일부 기능이 꺼질 수 있습니다.
- 드래그가 불편하면 `폴더로 이동`이나 `미분류 일괄 이동`을 쓰세요.
- 미사용 데이터는 지금은 없는 프리셋, 로어북, 캐릭터, 정규식 목록에 남은 Foldy 기록입니다.
- 1.9.0부터 폴더 데이터를 더 작은 형식으로 저장합니다. 업데이트 후 처음 실행할 때 자동으로 바뀌고 이전 데이터는 `user/files/foldy-v1-backup.json`에 3일간 보관된 뒤 지워집니다.
- 1.9.0에서 이전 버전으로 되돌리면 폴더가 보이지 않습니다. 다시 업데이트하면 돌아옵니다.
